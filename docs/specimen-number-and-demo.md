# 檢體流水號與示範分析

先在 Supabase SQL Editor 執行 `supabase/migrations/202610190003_sample_serial.sql` 的全部內容。需先完成 001、002；顯示 Success 後重新整理本機網站。

檢體欄位唯讀，建立檢測時由資料庫產生 `SMP-00000001`、`SMP-00000002` 等流水號，並儲存在 examinations.sample_id、analysis_records.sample_id。失敗重試使用同一 examination UUID，沿用同一流水號。多人新增由資料庫 sequence 避免重號；取消或失敗可能留下跳號，不保證連號。既有手動檢體編號不會改寫。SQL 可重複執行。

病患介面不再顯示 patient_code 或 UUID；搜尋姓名與身分證／病歷識別碼，歷史顯示遮罩識別碼。內部 UUID 和既有 patient_code 保留供外鍵、去重與歷史關聯使用；不以可能缺漏、更正或重複的身分證取代外鍵。

新上傳照片或影片都顯示完整分析結果頁，以簡短「示範分析」標記固定測試數值。影片保持原檔私有保存，尚未執行真正影片辨識、抽格或活動力計算。未來後端應替換示範數值與標記；原有待分析紀錄不自動回填假結果。沒有刪除或自動上傳原有本機資料。

本機驗證包含 64 個自動測試、42 個隔離資料庫斷言，以及 lint、型別檢查與 build；沒有連線修改遠端資料庫或部署。
