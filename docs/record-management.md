# 檢測紀錄修改與刪除

先完成 001–003，再將 `supabase/migrations/202610200004_record_management.sql` 全部內容貼到 Supabase SQL Editor 執行。SQL 可重複執行，並包含 API 快取更新。執行完成後重新整理本機網站。

入口：分析結果頁、單筆檢測詳情，以及病患歷史展開區的「修改檢測／刪除檢測」。

可修改：檢測日期、濃度、活動力、正常型態、精液量、pH、總精蟲數、顏色、外觀與摘要。量測單位沿用紀錄，留白表示 null。修改不自動推算其他量測；例如改變濃度時，總數仍需自行確認。檢體編號、病患關聯與檔案不可在此更改。

修改後清除審核者、審核時間及審核備註，重設參考判讀並回到待複核；已建立的報告版本保留原始快照。使用 updated_at 比對避免覆寫其他人的新修改。

刪除需二次確認。採軟刪除，新增 analysis_records.deleted_at（時間）、deleted_by（auth.users 外鍵），不真正移除資料列。歷史、圖表與首頁統計都透過同一個排除 deleted_at 非空紀錄的查詢載入；檢測前病患歷史預覽亦排除。病患主檔、報告、寄送紀錄及私有媒體保持完整，刪除不釋放儲存空間。管理者仍能在資料庫看到紀錄，尚未提供介面還原功能。

manage_analysis_record RPC 沿用已登入人員共用修改權限，未開放 DELETE 或公開檔案權限，不需要管理金鑰。
